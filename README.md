# Street Market

Catálogo web local para Street Market, boutique de streetwear & designer. Las fichas destacadas se transcribieron de publicaciones públicas de Instagram; cada una enlaza a su post original para verificar los datos y consultar disponibilidad.

## Vista local

Desde esta carpeta ejecuta:

```powershell
python -m http.server 4174
```

Luego abre `http://localhost:4174`.

Los enlaces llevan a los canales oficiales del perfil suministrado. Los precios y tallas reflejan lo que figura en las publicaciones consultadas y pueden cambiar; confirmar disponibilidad directamente con la tienda.

## GitHub Pages

El repositorio se publica desde `main` en la raíz (`/`). No necesita proceso de build: es HTML, CSS y JavaScript estáticos.
